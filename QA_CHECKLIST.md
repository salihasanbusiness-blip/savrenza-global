# SAVRENZA ENERGY — Pre-launch checklist

- Deploy first to a Cloudflare Pages preview environment.
- Check language switching across all 10 languages, including switching back to English. Translations are incomplete; verify each section manually.
- Check flags and phone dial code on iPhone Safari, Android Chrome, and desktop browsers.
- Confirm that the form opens a mail draft; **it does not submit to a backend**.
- Configure a server-side form handler with anti-spam and secure storage before advertising direct submissions.
- To enable live AI, set OPENAI_API_KEY, AI_ENABLED=true, TURNSTILE_SITE_KEY and TURNSTILE_SECRET securely in Cloudflare; validate supported model and API pricing.
- Validate Arabic right-to-left layout, keyboard access, color contrast, and responsive behavior.
- Confirm canonical domain, DNS, HTTPS, privacy notices, and business disclosures before public launch.
- Submit sitemap to Google Search Console only after domain is active.
- Do not claim guaranteed savings, partners, investment opportunities, or search rankings.
