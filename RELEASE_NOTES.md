# SAVRENZA ENERGY V8.1 — stability and language controls

- Added locally hosted flag images to a 10-language button grid, synchronized with the existing select control.
- Current language button displays a local flag.
- Added keyboard focus styling and narrow-screen layout for language options.
- Preserved existing functionality, backend worker, and disclosures.
- Marked 404 as noindex.

## Known limitations
- Translations are partial; legal pages remain primarily English.
- Email form opens the visitor’s mail client; no server-side delivery.
- AI requires Cloudflare secrets, explicit activation, and Turnstile configuration.
- Currency selection is not foreign-exchange conversion.
- This package has NOT been visually verified on live iPhone/desktop browsers.
- Test on a staging Pages deployment before production.
